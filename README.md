## What TrueVector helps you do

- **Use AI-generated artwork in a vector workflow.** Bring a logo or illustration from a tool such as ChatGPT or Gemini, then inspect the traced paths in your design editor.
- **Control colors.** Choose automatic processing, black and white, grayscale, gradients or a custom palette; inspect the result because forced palettes can change color assignments.
- **Control the background.** Keep native transparency or choose the available background treatment.
- **Choose a drawing workflow.** Filled shapes, centerlines or both, with grouping and stroke controls where applicable.
- **Download SVG and a preview.** The website currently exposes SVG/PNG downloads. This is not a native layered AI project or editable font reconstruction.

### A practical workflow

1. Upload a clean image you have permission to process.
2. Choose colors, background and drawing settings.
3. Convert, compare the preview and inspect important details.
4. Download SVG, open it in your vector editor and make any final corrections.

Image uploads currently accept PNG/JPG/WebP up to **20 MiB**, with each dimension no greater than **5000 pixels**. Large inputs may be normalized to protect processing resources.

## Honest quality notes

Good input matters. Blurred edges, tiny text, JPEG damage, complex shading and forced color palettes can require manual correction. Tracing cannot recreate missing information, recover original layers, or identify licensed fonts automatically.

The ten cases took **0.426–12.551 seconds of engine processing**, with a **1.885-second median** in this small test. These are not promised response times: cloud startup, transfer, queueing, image complexity and settings add time. The engine computations measured here used CPU; GPU availability is not claimed as CUDA acceleration.

The shaded mascot needs review; the forced-palette and three-color transparency cases have visible color reassignment; centerline results need a different evaluation from filled shapes. See the complete [methodology and limitations](BENCHMARK.md).
